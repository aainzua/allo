---
name: allo
description: Use the local Allo CLI when the user asks for Allo. For Jira via Allo, load allo-jira if available.
---

Use `allo discover` for operations, `allo describe operation <name>` for schemas, and pipe JSON into `allo call <name>`. Check `ok` before reading `result`.

On `profile_not_found`, use a known profile with `--profile <path>` or ask for its path.
